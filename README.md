Piedra, papel o tijera — BBC micro

Autor: Wilfran David Guerra Cuadros
Curso: 11-7
Institución: INEM Simón Bolívar

Este proyecto consiste en un juego de piedra, papel o tijera hecho con una BBC micro y MicroPython. Al agitar la placa, el programa elige al azar una opción y muestra una figura en la pantalla LED.

Cómo funciona?
Detecta la sacudida, elige una de las tres opciones y muestra el resultado. El juego puede repetirse varias veces.

Prompt Usado:
Ayúdame a crear un juego sencillo de piedra, papel o tijera para micro con MicroPython, que se active al agitar la placa, elija una opción al azar y la muestre en los LED. Usa una función, condicionales y un ciclo, y explica el código con palabras fáciles
